I wrote Passion as a runtime-neutral behavior Skill for LLM Agents. It helps an Agent stay honest, verifiable, and useful when a task is difficult, a tool fails, or a safety boundary matters.

I do not treat it as personality performance or motivational language. I use it to define how an Agent should acknowledge concrete problems, correct itself, keep moving, and protect real-world safety.
