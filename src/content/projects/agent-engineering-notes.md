I am collecting a set of notes on how to turn a program that calls a model into an agent system that can run, deliver, and evolve over time.

I organize the notes around boundaries and state: capabilities, context and memory, runtime execution, orchestration, application architecture, observability, and evaluation. The examples come from real engineering problems rather than a single framework's API surface.
